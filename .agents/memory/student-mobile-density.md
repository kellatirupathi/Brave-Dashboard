---
name: Student mobile density
description: Mobile-only layout and title hierarchy for authenticated student screens.
---

Authenticated student screens in the installed app should use compact cards, restrained typography, and tight section spacing. The app bar is the sole screen-level title, so do not repeat the same page heading at the top of the content. Keep meaningful entity names, such as a team or project name.

**Why:** The user explicitly wants the installed student experience to feel like a space-efficient mobile app rather than a desktop page compressed onto a phone.

**How to apply:** Scope density and duplicate-heading changes to the installed mobile student shell. Do not alter desktop presentation or remove content-specific headings that identify the current entity.
