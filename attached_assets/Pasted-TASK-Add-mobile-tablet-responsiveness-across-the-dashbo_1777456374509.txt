STANDARD PATTERNS TO APPLY
A. Sidebar
   - ≥ lg: untouched (fixed left column).
   - < lg: hidden by default, slide-in drawer triggered by a hamburger
     in the navbar. Use existing shadcn `Sheet` component.
B. Navbar / page header rows (title + action buttons)
   - Add `max-md:flex-col max-md:items-stretch max-md:gap-3`.
   - Long titles: `max-md:text-2xl` (keep desktop text-3xl).
   - Action buttons: `max-md:w-full max-md:justify-center` and stack
     button groups vertically.
C. Search + filter rows
   - Stack vertically below md, full-width inputs, full-width Selects.
D. Tables → cards below md
   - Wrap each <Table> with: `<div className="max-md:hidden">` for the
     existing table, then add a sibling `<div className="hidden max-md:block space-y-3">`
     that maps the same items into Card components showing the same
     fields stacked vertically (label : value pairs). Action buttons
     go to a footer row in the card.
   - Pagination footer: `max-sm:flex-col max-sm:gap-2`.
E. Dialogs (AlertDialog / Dialog / Sheet)
   - Add `max-md:max-w-[calc(100vw-2rem)] max-md:mx-4` to content,
     and `max-md:flex-col max-md:gap-2` to footers so buttons stack.
F. Forms
   - Two-column grids → `max-md:grid-cols-1`.
   - Long labels: `max-sm:text-sm`.
G. Cards / stat tiles grids
   - `grid-cols-4` → add `max-lg:grid-cols-2 max-sm:grid-cols-1`.
H. Horizontal scroll fallback
   - For tables you cannot reasonably stack (audit-log, leaderboard
     with many numeric columns), wrap in
     `<div className="max-md:overflow-x-auto">` instead of stacking.
I. Touch targets
   - Icon-only buttons under md must be at least h-10 w-10.
   - Add `max-md:h-10 max-md:w-10` to small icon buttons in tables.
J. Typography
   - Body text already fine. Page H1: keep desktop, add
     `max-md:text-2xl max-sm:text-xl` only.
