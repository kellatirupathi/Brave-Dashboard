Add a new HIDDEN admin-only page: "Campus Insights".

ROUTE & VISIBILITY
- Path: /admin/campus-insights
- Wired in artifacts/brave-dashboard/src/App.tsx via <ProtectedRoute component={...} allowedRoles={["admin"]} />.
- DO NOT add a sidebar/nav link anywhere. The page is reachable only by typing the URL directly.

PAGE LAYOUT (top → bottom)
1. Header row (left → right):
   - Search input (placeholder "Search campus or team…"), 250ms debounced. Filters the rows of the currently visible table by name.
   - Campus filter dropdown. Default: "All campuses". Options: "All campuses" + every row from the campuses table (alphabetical).
   - Export button with a dropdown menu of TWO items:
       (a) "Campus-wise CSV"  → downloads ONE CSV file for the currently selected campus.
                                 If "All campuses" is selected, downloads a ZIP of one CSV per campus.
       (b) "All campuses (single CSV)" → ONE CSV file containing all campuses' rows.
                                 The CSV has a single header row at the top and every data row carries a "Campus" column
                                 so the data stays flat and pivotable.
   - Filename format: `campus-insights-<view>-<YYYY-MM-DD>.csv` (or `.zip`).
2. Optional summary strip (3 cards): Total verified revenue, Total teams, Total journals submitted (national totals).
3. Main table (see views below).

TWO TABLE VIEWS
The view is decided by the campus filter:

VIEW A — "All campuses" (default). Each row = one campus.
Columns: Campus name | No. of teams | Journals submitted | Verified revenue (count) | Rejected revenue (count)
Clicking a campus name row drills into VIEW B for that campus (sets the filter and updates the URL).

VIEW B — a specific campus is selected. Each row = one team in that campus.
Columns: Team name | Journal weeks submitted (formatted "X / <total programme weeks>") | Order book submitted (count) | Verified revenue (count) | Rejected revenue (count) | Total verified amount (₹, lakh notation)
Show a "← Back to all campuses" breadcrumb that clears the filter.

ROW SORT ORDER (top → bottom, same logic for both views)
Tier 1: rows that have BOTH verified revenue > 0 AND ≥ 1 journal submitted.
Tier 2: rows that have ONE of (verified revenue > 0) OR (≥ 1 journal submitted).
Tier 3: rows that have rejected revenue > 0 (and none of the above).
Tier 4: everything else.
Within each tier sort by Total verified amount DESC, then by name ASC.
Column headers should remain click-sortable; clicking a header overrides the tier sort.

DATA
- Add a new admin-only API endpoint that returns aggregates server-side (one query per view, no N+1):
  GET /api/admin/campus-insights              → VIEW A rows
  GET /api/admin/campus-insights/:campusId    → VIEW B rows
- Counts are computed from the existing tables:
  * Teams: teams table
  * Journals submitted: weekly_journals
  * Verified revenue (count + sum): revenue_entries where status='verified'
  * Rejected revenue (count): revenue_entries where status='rejected'
  * Order book submitted (count): order_book_entries where status IN ('submitted','verified')
  * Programme weeks total: programme_weeks
- Reuse the generated Orval/React Query stack: extend lib/api-spec, run the codegen (`pnpm --filter @workspace/api-spec run codegen`), and consume the generated hooks on the page.

URL STATE
- Persist the campus filter and search term in the URL query string (`?campus=<id>&q=<search>`). Refresh and deep-linking should restore the same view.

UI / UX
- Use the existing shadcn/ui primitives (Table, DropdownMenu, Input, Button) and current page styling (see /admin/teams as the reference).
- Sticky table header, zebra rows optional.
- Empty state: "No campuses/teams match this filter."
- Loading state: skeleton rows.
- Admin-only access — reuse ProtectedRoute with allowedRoles=["admin"]; non-admins redirected.
- All currency in ₹ with Indian lakh notation (e.g. ₹1,50,000).

ACCEPTANCE CRITERIA
- Hitting /admin/campus-insights as an admin shows VIEW A by default; non-admins are redirected.
- Selecting a campus (or clicking a row) switches to VIEW B and updates the URL.
- Search box live-filters visible rows in the current view.
- Export → "Campus-wise CSV" downloads one CSV (or ZIP when on "All campuses").
- Export → "All campuses (single CSV)" downloads one flat CSV with a "Campus" column on every row.
- Sort tiers behave as specified; a clicked column header overrides them.
- No sidebar/nav link is added anywhere — page is discoverable only by URL.

NON-GOALS
- No changes to existing pages.
- No public/student access.
- Do not break the existing admin sidebar.
