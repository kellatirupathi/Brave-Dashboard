Implement a one-time intro video popup for students and a permanent video link
in the sidebar footer. Here are the full requirements:

---

GOOGLE DRIVE VIDEO EMBED FORMAT

The video is hosted on Google Drive.
Always use the preview embed format for the iframe:
  https://drive.google.com/file/d/{FILE_ID}/preview

Embed it using an iframe like this:
  <iframe
    src="https://drive.google.com/file/d/{FILE_ID}/preview"
    width="100%"
    height="100%"
    allow="autoplay"
    allowFullScreen
  />

Replace {FILE_ID} with the actual Google Drive file ID from the provided link.
Do NOT use the /view or /edit or direct download format — only /preview works 
for embedding inside an iframe.

---

FEATURE 1 — ONE-TIME VIDEO POPUP

Behaviour:
- When a student opens the dashboard for the first time, show a popup in the
  center of the screen with the embedded Google Drive video
- The popup must appear on top of everything with a dark overlay behind it
- The popup has a close (X) button at the top right corner
- When the student clicks X, close the popup and store in localStorage:
  key: "brave_intro_video_dismissed"
  value: "true"
- On every subsequent visit or login, check localStorage first
- If "brave_intro_video_dismissed" === "true" → never show the popup again
- No database change needed — localStorage handles this per browser per student

Popup UI:
- Dark semi-transparent overlay covering the full screen (z-index on top of all)
- Centered modal/card with rounded corners, max width 720px
- Title at the top: "Welcome to BRAVE Dashboard"
- Short subtitle: "Watch this quick intro to get started"
- Google Drive video embedded using iframe with /preview format
- iframe height should be 16:9 aspect ratio (e.g. width 100%, height 405px)
- Close (X) button at top right corner of the card
- Clicking X dismisses the popup and sets localStorage flag — never shows again
- Popup must NOT close when clicking the dark overlay — only X button closes it
- Video does NOT autoplay — student presses play manually inside the iframe

Where to add:
- Add the popup component in the student dashboard page
- Only show for role = "student"
- Check localStorage on component mount — if already dismissed, render nothing

---

FEATURE 2 — PERMANENT VIDEO LINK IN SIDEBAR FOOTER

Behaviour:
- Add a small clickable item at the bottom of the student sidebar
- Placed below the last nav item (below Resources)
- When clicked, opens the same popup component with the Google Drive video
- Always visible regardless of whether the popup was already dismissed
- Gives students a way to rewatch the intro video anytime

Sidebar footer UI:
- Small link with a play circle icon: "Watch intro video"
- Subtle muted color styling, small font, not distracting
- Sits at the very bottom of the sidebar just above the user profile section
- Clicking it sets a local state to open the popup — does NOT reset localStorage

---

TECHNICAL NOTES:
- localStorage key: "brave_intro_video_dismissed"
- Only for student role — coordinators and admins never see this popup or link
- Reuse the same popup/modal component for both auto-show and sidebar click
- The popup component accepts: open (boolean) and onClose (function) props
- Video URL placeholder: https://drive.google.com/file/d/PASTE_FILE_ID_HERE/preview
- Replace PASTE_FILE_ID_HERE with the real Google Drive file ID before deploying
