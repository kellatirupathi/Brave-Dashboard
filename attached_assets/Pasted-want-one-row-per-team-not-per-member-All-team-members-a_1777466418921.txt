Member Column Layout — Per Member (5 fields per slot)
For each of the 5 member slots, these columns repeat:

Column	Source
Member N — Name	users.firstName + ' ' + users.lastName
Member N — NIAT ID	users.niatId (e.g. N24H01A0550)
Member N — User ID	users.formsUserId (UUID from Forms SSO)
Member N — Email	users.email
Member N — Role	Leader or Member (based on team.leaderId)
So for 5 member slots × 5 fields each = 25 member columns per row.
Plus team-level columns (~8) = ~33 total columns per row in the National tab.

How Empty Slots Are Handled
A team with only 2 members → Member 1 and Member 2 columns filled, Member 3/4/5 columns left blank (empty cells)
A team with 5 full members → all slots filled
A team with 0 members yet (rare) → all member columns blank, team-level data still shown
How Members Are Ordered Inside a Row
Consistent ordering so it's predictable:

Slot 1 = Team Leader (always first)
Slots 2–5 = Other members sorted by join date (oldest first) or alphabetically by name
Why This Layout Makes Sense
✅ One row per team = easy to scan ranks down the column
✅ Members horizontal = the whole team is visible on one row, no scrolling between rows to see who's on which team
✅ Filterable = admin can filter by Campus, Rank, Demo Day Eligible without losing member visibility
✅ Easy VLOOKUP / pivots in Excel since each team is a single row anchor
