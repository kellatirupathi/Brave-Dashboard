Make sidebar profile clickable with right-side dropdown ("Edit profile" + "Logout")
In the left sidebar, the profile block at the bottom (avatar + name + role) must become clickable. On hover it shows a pointer cursor; on click it opens a dropdown popup positioned to the RIGHT of the profile block (not below, not above) containing two items:

Edit profile (text button) — top
Logout (text button) — bottom
This must apply to all roles — Admin, Coordinator, and Student — wherever the bottom profile block currently renders in the sidebar.

1. File to change
artifacts/brave-dashboard/src/components/sidebar.tsx (or whichever file owns the bottom profile block — look for the element rendering the avatar circle, the user's first name, and the role label like "Admin" / "Student" with the small logout/exit icon next to it).

2. Behavior
The entire profile block (avatar + name + role) is wrapped in a DropdownMenu trigger.
Hover: cursor-pointer + subtle background hover (hover:bg-white/5 or matching the sidebar's existing hover style).
Click: dropdown opens immediately.
Position: <DropdownMenuContent side="right" align="end" sideOffset={8}> so it pops out to the right of the profile block, anchored to the bottom-right corner of the trigger.
Click outside or press Esc → dropdown closes (default shadcn DropdownMenu behavior).
The existing standalone exit icon currently inside the profile block must be removed — logout now lives inside the dropdown.
